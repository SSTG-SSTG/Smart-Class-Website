# Smart Class Website 📚

## About
Smart Class is an interactive educational website designed to make learning simple, engaging, and accessible. It provides digital study materials and learning resources to help students improve their knowledge and academic performance.

## Features
- 📖 Digital Learning Resources
- 🎓 Student-Friendly Interface
- 💻 Simple and Responsive Design
- 📚 Easy Access to Study Materials

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
To provide a simple digital learning platform that supports students in their educational journey.
